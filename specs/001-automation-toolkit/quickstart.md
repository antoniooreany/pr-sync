# Quickstart Validation Guide

## Prerequisites
- Python 3.11+
- `gh` CLI installed and authenticated (`gh auth status`)
- A git repository with uncommitted or committed changes on a branch

## Validation Scenario: Dry Run `pr-sync`
1. Navigate to a repository with unmerged changes on a branch.
2. Execute the toolkit CLI:
   ```bash
   python -m src.toolkit.cli pr-sync --dry-run
   ```
3. **Expected Outcome**: The tool outputs a standardized Markdown PR body (Summary, Changes, etc.) generated by the docs engine, without actually modifying GitHub.

## Validation Scenario: Create PR
1. Commit changes to a new branch (e.g., `feature/test-sync`).
2. Run:
   ```bash
   python -m src.toolkit.cli pr-sync
   ```
3. **Expected Outcome**: A PR is successfully created on GitHub for the current branch. The PR body contains the generated sections.
